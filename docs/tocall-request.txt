Subject: New TOCALL registration request: APRGQ (Aurora Beacon)

Hello Hessu,

I would like to register a new TOCALL for an open-source Android APRS-IS
client, so that aprs.fi shows a proper device name instead of
"Unknown: Unknown".

  TOCALL      : APRGQ
  Software    : Aurora Beacon (极光信标)
  Description : Android APRS-IS position beacon. Uploads standard
                uncompressed position reports to APRS-IS over TCP
                (no RF, no messaging, no weather), 188 APRS symbols,
                user-editable comment.
  Author      : BH6RGQ
  Source code : https://github.com/Honest16888/aurora-beacon
  License     : Apache-2.0
  Platform    : Android 8.0+ (minSdk 26)
  Example     : BH6RGQ-15>APRGQ,TCPIP*:!3050.78N/11419.05E>AURORA GPS 4G

A few details that may be useful:

  * Connects to *.aprs2.net:14580; login line is
        user BH6RGQ-15 pass <passcode> vers AuroraBeacon 1.4.2
  * Sends position reports only; no RF path (TCPIP*), no messages.
  * The TOCALL is hardcoded to APRGQ in the packet builder.

If APRGQ is already taken, or does not fit the naming convention,
please let me know a free code and I will switch to it in the next
release.

73 de BH6RGQ
