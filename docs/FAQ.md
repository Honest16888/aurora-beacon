# 常见问题

## 崩溃相关

### Q：打开就闪退怎么办？

先拿日志，比猜快一百倍：

```
/sdcard/Android/data/com.yg.aprs/files/crash.txt
```

这个文件由应用自带的 `CrashGuard` 写入，包含完整堆栈。没有这个文件（例如崩溃发生在
`CrashGuard.install` 之前）时用：

```bash
adb logcat -d -s AndroidRuntime:E
```

本项目历史上出现过三次启动闪退，根因都在 [CHANGELOG](../CHANGELOG.md) 里写明了：

| 版本 | 根因 |
|---|---|
| 1.1.0 之前 | `const/4 v5` 覆盖了仍当作字符串读取的 `v5` |
| 1.2.0 | 误用 `View.getChildAt`（应为 `ViewGroup`）→ 点图标闪退 |
| 1.3.0 | `.registers 3` + 2 个参数，`const-class v1` 覆盖了 `p0`(this) → 启动闪退 |

### Q：装上 1.3.0 一打开就闪退？

那是已知问题，升级到 **1.4.x** 即可。

### Q：点 APRS 图标闪退？

1.2.0 的问题（`getChildAt` 方法归属错误）。1.2.1 起图标行改为纯代码构建，1.4.x 正常。

## 状态显示相关

### Q：状态卡"网络"显示"未知"？

已修。原因：清单缺少 `ACCESS_NETWORK_STATE`，`ConnectivityManager.getActiveNetwork()`
抛 `SecurityException` 被兜底 catch 吞掉。1.2.2 起正常显示：

| 场景 | 显示 |
|---|---|
| 无网络 | 离线 |
| Wi-Fi | WiFi |
| 蜂窝 + 已给电话权限 | 中国移动 4G |
| 蜂窝 + 未给电话权限 | 中国移动 蜂窝 |

### Q：为什么蜂窝只显示"蜂窝"，不显示 4G/5G？

读网络制式需要 `READ_PHONE_STATE`（危险权限），本应用**没有**做运行时申请弹窗。
想要细分到 2G/3G/4G/5G：

```
系统设置 → 应用 → 极光信标 → 权限 → 电话 → 允许
```

不给也不影响上报，只是备注里的制式退化成"蜂窝"。

### Q：电量/电压、基站小区显示 `--`？

- 电量：部分 ROM 限制读取，或服务尚未取到第一帧状态
- 基站小区：需要定位权限 + 蜂窝网络；纯 Wi-Fi 环境读不到

### Q：定位源一直是"网络"不是"GPS"？

- 室内/车内 GPS 无信号时会退化到网络与基站定位（精度数百米）
- 检查系统定位是否开启、是否给了"精确位置"
- 首次冷启动可能需要 30–120 秒才拿到 GPS 定位

## 上报相关

### Q：App 显示在跑，aprs.fi 上却看不到我？

按顺序排查：

1. **密码对不对**：顶部胶囊是算出来的值，点一下复制。呼号写错一个字符密码就错
2. **服务器返回 `unverified`**：说明密码错。APRS-IS 会拒绝发送
3. **SSID**：aprs.fi 搜的是 `呼号-SSID`，比如 `BH6RGQ-15`，不是只搜 `BH6RGQ`
4. **间隔太长**：默认 60 秒，aprs.fi 也有索引延迟（通常 10–30 秒）
5. **位置非法**：见 [docs/APRS.md](APRS.md) 的"看不到我"一节
6. **aprs.fi 时间窗**：默认只显示最近 3 小时，用 `?timerange=` 调整

### Q：密码算出来是 `-1` / `0` / 数字很小？

- `-1` 表示当前没有连接 APRS-IS（只读观察用），不是密码
- 密码范围是 `0–32767`，出现很小的数字是正常的

### Q：能改上报内容吗？

可以，两处：

- **备注**：「包备注」留空 = 自动 `AURORA 定位源 网络 电量`；填写则完全自定义（≤40 字符）
- **报文结构**：改 `AprsService.buildPacket`，参考 [docs/APRS.md](APRS.md)

### Q：能同时报两个呼号吗？

不能。当前实现是单实例服务、单一呼号。多呼号切换在 [路线图](../README.md#路线图) 里。

### Q：有没有"立即发送一次"？

暂时没有，只有定时循环。点「启动上报」后等一个间隔即可。

## 后台与耗电

### Q：锁屏一会儿就停止上报了？

- 本应用使用前台服务 + WakeLock，理论上锁屏继续跑
- 但国产 ROM 会额外杀进程，需要手动设置：
  - MIUI：设置 → 应用 → 极光信标 → 省电策略 → **无限制**；允许自启动
  - EMUI/ColorOS/Flyme：允许后台活动 / 忽略电池优化
  - 通用：设置 → 电池 → 电池优化 → 找到本应用 → **不优化**
- Android 13+ 还需要允许通知，否则前台服务通知不显示（服务仍可运行）

### Q：耗电吗？

间隔 60 秒 + GPS 常开时，约每小时 3–6% 电量（视机型）。想省电：

- 把间隔调到 300 秒以上
- 只在需要时启动，用完停止

## 其他

### Q：图标列表里图标和文字对不上？

图标按 ASCII 顺序与标签一一对应（`index = code - 0x21`）。若错位，说明
`arrays.xml` 的 `symbol_labels` 顺序被改动过——改顺序必须同时改 `symbol_icons` 与
`MainActivity.SYMBOL_CHARS`。

### Q：能做成标准 Gradle 工程吗？

技术上可以（把 smali 反编译回 Java 后重建），但工作量远大于收益，且容易破坏现有资源。
当前混合构建的好处是"改哪层都行"，见 [docs/BUILD.md](BUILD.md)。

### Q：支持 iOS / 鸿蒙 / 电脑吗？

只有 Android（8.0 / API 26 及以上）。鸿蒙可通过 Android 兼容层安装，未专门测试。

### Q：会收集我的数据吗？

不会。只与你设置的 APRS-IS 服务器通信，发送的就是 APRS 报文本身；设置仅存本机；
崩溃日志只写本地文件、不自动上传。详见 [SECURITY.md](../SECURITY.md)。
